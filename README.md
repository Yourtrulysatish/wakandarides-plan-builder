# WakandaRides Plan Builder

Interactive pricing calculator for the WBB x WakandaRides proposal. Static page, no build step.

- Rates and defaults live in the `wbb-data` JSON block in `index.html`.
- "Send to WBB" posts the plan to [FormSubmit](https://formsubmit.co), which emails each submission to the address in `SUBMIT_URL`.
